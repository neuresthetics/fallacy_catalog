# Tests

This folder holds every test run against the catalog: the passages, the answer keys (with every change the scorer made to them), both reviewers' verdicts and notes, the scores, the fixes made in response, and the scripts that compute the scores. See the main [README](../README.md#testing) for the protocol and a summary of results.

## Layout

| Path | Contents |
|---|---|
| `round1/` | 120 passages (50 legit, 50 fallacy, 20 borderline). Reviewers A and B. Catalog v0.3.0. |
| `round2/` | 100 passages (40 legit, 20 no-argument, 40 fallacy). Reviewers C (strict literal) and D (practical). Catalog v0.4.0. |
| `round3/` | 100 passages (43 legit, 11 no-argument, 35 fallacy, 11 mixed), 20 of them real public-domain excerpts. Reviewers E (strict literal) and F (practical). Catalog v0.5.0. |
| `regression/` | Non-blind re-checks after the v0.5.0 and v0.6.0 fixes (with a v0.6.1 note on the two dropped entries). |
| `audit/` | The two independent audits of the catalog that came before blind testing. |
| `idea_detection/` | Checker tests and miss-taxonomy scoring tests. The scoring module is [`idea_detection/score_eval.py`](../idea_detection/score_eval.py). The development loop is [`idea_detection/DEV_PROCESS.md`](../idea_detection/DEV_PROCESS.md). |

Each round folder contains:

| File | Contents |
|---|---|
| `passages.csv` | The passages exactly as the reviewers saw them (`id`, `passage`). |
| `answer_key.csv` | The answer key written with the passages, **as adjudicated**. Where the scorer overruled the key, `original_key` holds the original values (JSON, field → value) and `overrule_reason` says why. Round 2 also has the set writer's design notes (`design_type`, `trap_sentence`); round 3 has `source_citation` for real excerpts. |
| `verdicts_X.csv` | Each reviewer's verdicts: verdict, entry ids, quoted error sentence (rounds 2–3), the evidence for each condition, the look-alikes ruled out, and notes. Round 3 has one row per argument step, so a passage can have several rows. |
| `notes_X.md` | Each reviewer's own notes on the catalog. Local file paths were replaced with repository paths; otherwise the notes are verbatim. |
| `scores.md` | The scores. Generated by `score.py`. |
| `errors.csv` | Every scoring error, disagreement and fragile call, with its cause (catalog, reviewer or answer key) and the proposed fix. |
| `FIXES.md` | What was changed in the catalog in response, followed by the scorer's recommended fixes as written. |
| `score.py` | The scoring script. The scorer's label judgments and adjudications are hard-coded in it, so the scores can be audited line by line. |

Round 3 also has `real_excerpt_sources.csv`: the full citation (author, work, edition, chapter or section) and URL for each of the 20 real excerpts. All are public-domain texts, 18 from Project Gutenberg and 2 from Wikisource.

## Reproducing the scores

Run from the repository root. Each script reads only files in its own round folder and rewrites that round's `scores.md`. Python 3 standard library only.

```
python3 tests/round1/score.py
```

```
python3 tests/round2/score.py
```

```
python3 tests/round3/score.py
```

```
git diff --stat tests/
```

The last command should show no changes. Each script scores against the original key (it restores the `original_key` values), and applies the adjudications through the judgments coded in the script, as in the original run. That is how `scores.md` reports both "as keyed" and adjudicated numbers.

| Round | Rows changed | Ids |
|---|---|---|
| 1 | 7 (6 key errors, plus 1 clarification of a reason that stated two leans) | P013, P068, P009, P019, P097, P092; P003 |
| 2 | 5 | Q054, Q010, Q014, Q003, Q049 |
| 3 | 6 | R021, R040, R041, R063, R092, R082 |

The scorer could overrule the key only with a stated reason. In most cases the overrule made the key accept the reviewers' answer, and the reasons are in `answer_key.csv` and `errors.csv`. Readers who distrust the adjudication can use the "as keyed" rows in each `scores.md`.
